## 과금 방식

메시온은 솔루션 이용료가 없어요. 메시지를 보낼 때만 건당 비용이 발생해요.

## 크레딧이란?

크레딧은 메시지 발송에 사용되는 선불 충전 단위예요.

| 구분       | 유상 크레딧 | 무상 크레딧  |
| -------- | ------ | ------- |
| **획득**   | 직접 충전  | 프로모션·보상 |
| **유효기간** | 5년     | 1년      |

무상 크레딧이 먼저 소진되고, 유효기간이 짧은 것부터 차감돼요. 발송 실패 시 크레딧은 **자동 환급**돼요.
