---
title: "쿠폰 발급하기"
---

쿠폰만료 메시지 발송을 위해 호스팅사에서 **다운로드 쿠폰**을 미리 발급해야 합니다. 발급 후 쿠폰 다운로드 URL을 추출해 메시온 메시지 쿠폰 다운로드 링크 URL을 입력합니다.

<Note>
  사용 중인 호스팅사를 선택해 가이드를 따라 진행해주세요.
</Note>

<AccordionGroup>
  <Accordion title="카페24">
    <Steps>
      <Step title="쿠폰 만들기">
        카페24 관리자 메뉴에서 [**프로모션 \> 쿠폰 관리 \> 쿠폰 만들기**](https://eclogin.cafe24.com/Shop/?onnode=1&menu=282)로 이동합니다.

        발급구분을 \*\*'고객 다운로드 발급'\*\*으로 선택합니다.
      </Step>
      <Step title="쿠폰 정보 설정">
        - 쿠폰 사용 기간 설정
        - 사용 정보 항목에서 구매자가 쿠폰을 사용하는 기준 설정
        - 혜택, 적용 범위, 최소 주문금액 등 설정 후 저장
      </Step>
      <Step title="쿠폰 다운로드 URL 복사">
        **프로모션 \> 쿠폰관리 \> 쿠폰 발급/조회**로 이동합니다.

        생성한 쿠폰의 **\[복사\] 버튼**을 클릭하면 쿠폰 다운로드 URL이 복사됩니다.

        <Note>
          복사한 URL을 메시온 메시지 본문 버튼 링크에 입력해 주세요.
        </Note>
      </Step>
    </Steps>

    자세한 가이드: [카페24 Help Center — 쿠폰 발급, 설정, 사용 방법](https://support.cafe24.com/hc/ko/articles/17426375006745)
  </Accordion>

  <Accordion title="고도몰">
    <Steps>
      <Step title="쿠폰 사용 활성화">
        고도몰 쇼핑몰 관리자에서 **프로모션 \> 쿠폰 관리 \> 쿠폰 기본 설정**으로 이동합니다.

        쿠폰 사용 설정이 \*\*\[사용함\]\*\*으로 되어있는지 확인합니다.
      </Step>
      <Step title="쿠폰 만들기">
        **프로모션 \> 쿠폰 관리 \> 쿠폰 등록**으로 이동합니다.

        - **발급 방식**: \[회원다운로드\]
        - 혜택, 사용 기간, 적용 상품 등 설정 후 저장
      </Step>
      <Step title="쿠폰팩 링크 생성">
        쿠폰 목록에서 **다운로드 쿠폰의 체크박스**를 체크합니다.

        좌측 상단 **\[쿠폰 링크 만들기\]** 버튼을 클릭하여 쿠폰팩 링크를 생성합니다.

        <Note>
          생성된 쿠폰팩 링크를 메시온 메시지 본문 버튼 링크에 입력해 주세요. 클릭 시 쿠폰이 자동 다운로드됩니다.
        </Note>
      </Step>
    </Steps>

    자세한 가이드: [고도몰 공식 쿠폰 만들기 가이드](http://guide.godo.co.kr/season3/board/view.php?id=event&no=12)
  </Accordion>

  <Accordion title="아임웹">
    <Steps>
      <Step title="쿠폰 만들기">
        아임웹 관리자 페이지에서 **프로모션 \> 쿠폰**으로 이동합니다.

        우측 상단 **\[쿠폰 만들기\] \> 고객 다운로드** 버튼을 클릭합니다.
      </Step>
      <Step title="쿠폰 정보 설정">
        - **쿠폰명** 입력
        - 발행대상, 쿠폰 수량, 혜택, 운영 설정
        - **시크릿 쿠폰** 옵션: 다운로드 링크만 생성되어 어디에도 노출되지 않음 (특정 고객용으로 활용 가능)

        설정 완료 후 저장합니다.
      </Step>
      <Step title="다운로드 링크 복사">
        생성한 쿠폰의 **쿠폰형식 \> 링크 아이콘**을 클릭하여 다운로드 링크를 복사합니다.

        <Tip>
          고객 다운로드 쿠폰을 **2개 이상 선택**하면 **\[다운로드 링크 합치기\]** 버튼이 활성화됩니다. 여러 쿠폰을 하나의 링크로 통합해 한 번에 다운로드되도록 만들 수 있습니다.
        </Tip>

        <Note>
          복사한 링크를 메시온 메시지 본문 버튼 링크에 입력해 주세요.
        </Note>
      </Step>
    </Steps>

    자세한 가이드: [아임웹 쿠폰 생성 및 관리하기](https://imweb.me/faq?mode=view&category=29&category2=40&idx=71399)
  </Accordion>

        **\[스마트 쿠폰 등록\]** 버튼을 클릭합니다.

        - **쿠폰 제공 방식**: \[다운로드\] 선택
        - **쿠폰 혜택**: 할인 / 적립 / 배송비할인 / 배송비무료
        - **사용 기간** 및 **노출 기간** 설정

        <Note>
          복사한 쿠폰 URL을 메시온 메시지 본문 버튼 링크에 입력해 주세요. (QR코드 생성은 다운로드 쿠폰만 가능합니다)
        </Note>
      </Step>
    </Steps>

    자세한 가이드: [메이크샵 고객센터 — 스마트 쿠폰](https://help.makeshop.co.kr/faq/undefined-1/undefined-1/undefined)

## 💡 발급 후 메시온에서 활용

쿠폰 다운로드 URL을 확보했다면, 메시온 메시지 작성 화면에서 다음과 같이 활용합니다.

1. 메시온 어드민 → 메시지 작성
2. 메시지 본문의 **버튼 링크 영역**에 복사한 쿠폰 다운로드 URL 붙여넣기

<Tip>
  **매월 새 쿠폰 발급 권장** — 매번 같은 쿠폰을 재발송하기보다, 시즌·이벤트에 맞춰 새 쿠폰을 발급하면 재구매율이 더 올라갑니다.
</Tip>
