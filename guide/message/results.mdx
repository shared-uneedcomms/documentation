### 발송 결과는 어디서 확인하나요?

메시지 목록에서 리스트를 클릭하면 메시지 상세 페이지로 이동해요. 상세 페이지에서는 **메시지 지표** 탭과 **메시지 상세 정보** 탭을 통해 발송 성과와 메시지 내용을 각각 확인할 수 있어요.

### 확인할 수 있는 지표
 
광고성 메시지 발송 후 확인할 수 있는 지표는 다음과 같아요.
 
| 지표 | 설명 |
| --- | --- |
| 성공\+유효 발송 수 | 총 발송 수 대비 성공적으로 전달된 건수 |
| 오픈 수 | 메시지를 열어본 건수 |
| 클릭 수 | 메시지 내 버튼을 클릭한 건수 |
| 오픈 대비 클릭률 | 오픈한 고객 중 클릭까지 이어진 비율 |
| 발송 내역 상세 | 성공/유효/실패 발송 건수 |
| 사용된 크레딧 | 총 크레딧, 유상·무상 크레딧 내역 |
 
<Tip>
  \[일자 별 상세\]를 클릭하면 오픈 수와 클릭 수의 일별 추이도 확인할 수 있어요.
</Tip>
