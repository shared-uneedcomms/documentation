## 1. 메시지 유형 선택하기

사이드바에서 \[메시지 작성하기\]를 클릭하면 메시지 유형 선택 화면으로 이동돼요.\
(1)활용 사례나 (2)원하는 메시지 유형을 선택하면 메시지 작성을 시작할 수 있어요!

## 3. 메시지 작성하기 - 혜택 정보

<Frame>
  ![Image](/images/image-47.png)
</Frame>

| 항목 | 설명 |
| --- | --- |
| **혜택 노출 케이스** | 일반 혜택 / 쿠폰 / 적립금<br />(\*쿠폰과 적립금 선택 시 혜택 정보를 메시지에도 노출할 수 있어요) |
| **혜택 뱃지** | 타임 세일 / 사은품 증정 / 브랜드 데이 / 1\+1 / 이벤트 중 최대 2개 선택 |
| **혜택 시작일** | 혜택 노출 시작 날짜 설정 |
| **혜택 종료일** | 혜택 노출 종료 날짜 설정 |

## 4. 작성 완료

<Frame>
  ![스크린샷2026 03 20오후2 55 32](/images/스크린샷2026-03-20오후2.55.32.png)
</Frame>

모든 항목을 입력한 후 우측 상단의 **\[작성 완료\]** 버튼을 클릭하면 발송 설정 단계로 이동해요. 작성 완료 후 이동되는 발송 설정 단계에서는 발송 대상, 발송 시간 등을 설정할 수 있어요.

[발송 설정하기 →](/guide/message/settings)

<Warning>
  **\[작성 완료\]** 버튼 클릭 후에는 **메시지 내용을 수정할 수 없어요. 모든 항목을 꼼꼼히 확인한 후 클릭**해 주세요.
</Warning>
